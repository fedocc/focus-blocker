# Учебная система для Mac: Слово + Anki + Focus Blocker

Готовая настройка для своей учёбы: план из Слова, несколько задач на блок,
80 минут фокуса, перерывы 10/30 минут, выбор приложений, защита от отвлечений,
таймер в строке меню, шесть тем обоев с семью состояниями суток и статистика учебных блоков.
Пять основных блоков, шестой по желанию. Следующий блок запускается вручную.

В комплекте только код и чистое оформление. Карточек, задач, аккаунтов,
ключей, истории и базы исходного пользователя нет. Anki и Onigiri устанавливаются
из официальных источников. Код Onigiri не распространяется здесь.

## Открой проект в Codex на своём Mac

Передай Codex такой запрос:

> Настрой мне эту учебную систему на Mac по START_HERE.md и CODEX_SETUP.md.
> Хочу оформление из theme/focus-study.onigiri, блоки 80/10/80/30,
> задачи из моего Слова и статистику фокуса. Проверь установленные приложения,
> помоги развернуть отдельное Слово из https://github.com/fedocc/slovo
> или подключить мой уже работающий экземпляр. Используй мои аккаунты и новый
> ключ Слова. Существующие карточки сохрани. После установки проверь интеграцию;
> длинный защищённый блок за меня не запускай.

Подробный порядок и проверки — [CODEX_SETUP.md](CODEX_SETUP.md).
GitHub хранит исходники; для Слова нужен работающий экземпляр сайта.
Для пробы можно запустить Слово на этом же Mac. Для совместной работы пары —
свой HTTPS-сайт по инструкции в репозитории Слова.

## Что появится в Anki

- Слева внизу — таймер, под Activity — задачи из планера.
- Вверху — переключатель «Карточки / Фокус».
- В режиме фокуса — часы, блоки, календарь, блокировки и история задач.
- Время по приложениям собирается с новых блоков при открытом Anki.
- Панель управления открывается по запросу, а не при каждом запуске Anki.
- «Обои · время суток» под таймером: город, море, архитектура, AMG GT, Rolls-Royce,
  Гоггинс и прежний пейзаж. Автоматическая смена по времени Mac или ручной выбор.

Слово отдаёт только свои ожидающие задачи; таймер не ставит отметку выполнения.
Доказательства и подтверждение остаются на сайте. Anki MCP необязателен и
подключается отдельно, если нужен доступ Codex к собственной коллекции.
