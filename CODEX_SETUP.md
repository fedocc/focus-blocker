# Инструкция для Codex: установка другу на macOS

Работай на Mac получателя. Не копируй чужой профиль Anki, `preferences.json`,
`study.json`, SQLite-базы, ключи, `.env` или `user_files`. Не запускай защищённый
80-минутный блок для проверки. Не архивируй карточки автоматически.

Если открыт уже подготовленный каталог с `instance.json`, проверь в нём
`planner_origin`: при правильном адресе шаг 3 уже выполнен. Для другого адреса
подготовь новый комплект из исходного репозитория, не меняй только клиент Anki.

## 1. Проверить среду и подготовить Anki

Нужны macOS, Anki Desktop и Python 3.9+ для служебных скриптов. Anki использует
собственный Python; системный Python в него не подменять. Открой Anki один раз,
чтобы появился каталог `~/Library/Application Support/Anki2/addons21`.
Если коллекция уже используется, сохрани её резервную копию перед установкой.

Anki: https://apps.ankiweb.net/ . В Anki установи Onigiri из AnkiWeb,
код дополнения **1011095603**: https://ankiweb.net/shared/info/1011095603 .
Не копируй стороннее дополнение из профиля автора этого проекта.
Текущая интеграция проверена на Anki 26.09.3, macOS arm64; на другой версии
проверь совместимость, не обещай неподтверждённую поддержку.

## 2. Собственное Слово

Исходники: https://github.com/fedocc/slovo . Сначала прочитай его актуальные
README.md и docs/deployment.md. Приложение создаёт новую пару, чужих данных нет.
Нужен Node.js 26. ИИ-наставник необязателен; для фокуса платный ИИ не нужен.

Если у получателя есть свой работающий сайт — используй его точный адрес.
Для пробы на одном Mac запусти Слово на `http://127.0.0.1:3000` по его README.
Сгенерируй собственный SETUP_TOKEN локально и сохрани вне Git; не помещай его
в ответы, коммиты или аргументы команд. Для удалённой пары используй собственный
домен, HTTPS и постоянный диск по docs/deployment.md. Не покупай VPS/домен
и не подключай оплату без отдельного поручения владельца.

Первое создание пары и пароли вводит владелец. На своём аккаунте:
«Меню → Учёба в Anki → Создать ключ для Anki». Этот новый ключ нужен позже;
не передавай его автору проекта и не публикуй в GitHub.

## 3. Собрать комплект под выбранный сайт

Из корня клонированного Focus Blocker выполни без sudo:

```sh
python3 prepare_friend.py --slovo-origin https://YOUR-SLOVO-DOMAIN
```

Для локальной пробы вместо HTTPS-адреса укажи `http://127.0.0.1:3000`.
Адрес обязателен: скрипт создаёт отдельный `dist/friend-setup` и меняет его
одновременно в клиенте и защищённой проверке ссылок. Исходный проект и уже
установленная система не меняются. Существующий каталог не перезаписывается;
при повторной подготовке укажи другой новый путь через `--output`.

```sh
cd dist/friend-setup
python3 doctor.py
```

Проверь учебные каналы и плейлисты в `youtube-policy.json` до установки.
Исходный пример содержит DL и Мопторий; получатель может выбрать свои.

## 4. Установить службу и дополнение

Закрой Anki. В подготовленном каталоге получатель запускает:

```sh
sudo /usr/bin/python3 -I install.py --anki
```

Либо открывает `install-study.command`. Пароль macOS вводит сам получатель.
Это устанавливает системную службу, правила hosts и ограниченные sudo-команды;
следуй обычной политике разрешений своей среды. Не обходи запреты среды через
другой интерпретатор или терминал. Если доступа нет — дай владельцу команду.
Автоматические запросы macOS Automation для своего браузера подтверждает владелец.

Если служба уже установлена, сначала дождись завершения блока/перерыва. Обычная
установка сохраняет историю и лимиты. `repair-study.command` нужен только для
ремонта по явному запросу владельца, прерывает текущий фокус и расходует выход.
Не используй его для обычной установки, демонстрации или смены белого списка.

При установке только интерфейса можно установить `slovo-study-blocks.ankiaddon`
через «Инструменты → Дополнения → Установить из файла». Без службы новые
защищённые блоки не запускаются; это не полная установка.

## 5. Оформление и связь с планером

Запусти Anki и импортируй `theme/focus-study.onigiri` через страницу тем
в настройках Onigiri. Примени импортированную тему; названия кнопок могут
зависеть от версии. Настрой имя получателя в профиле Onigiri. В теме выключен
второй помодоро Onigiri, чтобы он не дублировал наш системный таймер.
Выбери тему через «Обои · время суток» под таймером или в меню «Инструменты».
Шесть новых тем содержат по семь изображений и меняются по времени Mac:
05–07 предрассвет, 07–10 рассвет, 10–13 утро, 13–16 полдень,
16–18 золотой час, 18–21 закат, 21–05 ночь. Для просмотра можно выбрать
время вручную, затем вернуть «Автоматически». Выбор сохраняется в настройках.
Прежний пейзаж также доступен, у него остаются четыре исходных изображения.

«Инструменты → Учебные блоки · Слово → Подключить Слово»: владелец вставляет
свой новый ключ. Проверь, что отображаются его задачи. Старый ключ от другого
адреса не переносить. Выбери приложения для первого блока, включая браузер,
редактор и всё необходимое для учёбы. Anki, Фото и системные окна доступны всегда.

## 6. Проверить, не запуская блок

- Служба подтверждена, а Anki открывается без traceback.
- Задачи видны под Activity; несколько задач можно отметить одновременно.
- Панель не открывается сама при входе; таймер в строке меню включается через Tools.
- Проверь «Инструменты → Проверить сигнал окончания блока»: появляется отдельное
  окно и слышен звук. Он повторяется каждые 20 секунд до подтверждения, учебный
  таймер не меняется. Если звука нет, владелец проверяет громкость и аудиовыход.
  Anki нужно оставлять открытым; при повторном открытии во время отдыха сигнал
  восстановится, если ещё не подтверждён. Громкость и Focus macOS дополнение не меняет.
- «Карточки / Фокус» переключает показатели и графики; новая история пока пустая.
- Экранное время включается отдельно в Tools и собирается только в будущих
  блоках при открытом Anki. Оно показывает переднее приложение, а не внимание.
- На сайте Слова есть созданная самим владельцем задача, которая приходит в Anki.
- Карточки и существующая история получателя сохранены.

Первый реальный блок запускает владелец после выбора задач и приложений.
80 минут фокуса → 10 минут отдыха, следующий блок → 30 минут отдыха; новые блоки
не стартуют автоматически. Экстренный выход — с причиной, ожиданием 60 секунд,
точным подтверждением, один раз в день и минимум через 20 часов после прошлого.
Пароль администратора позволяет владельцу изменить службу; это защита от
импульсивных действий, а не неустранимая защита от администратора своего Mac.

Если нужен Anki MCP, подключи его отдельно через https://ankimcp.ai/ для
собственной коллекции владельца. Для обычного таймера/планера MCP не требуется.
