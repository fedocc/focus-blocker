# Focus Blocker

Локальный блокировщик YouTube, Instagram и Telegram Web для macOS. Продолжает существующую систему с блоками `FOCUS_BLOCK` в `/etc/hosts` и системным таймером launchd.

## Команды

```sh
youtube
instagram
telegram
telegram --set-minutes 10
```

YouTube принимает ссылку на конкретное видео: максимум два открытия одного видео за всю сохранённую историю. Instagram допускает одно открытие публикации или reel. Разные формы ссылки и параметры отслеживания считаются одним материалом. Ранее сохранённая история учитывается; новые отказы в выдаче доступа не расходуют лимит. Двухчасовой интервал между запусками YouTube/Instagram сохранён.

Telegram не спрашивает ссылку. Он открывает `https://web.telegram.org/` в браузере по умолчанию. На этом Mac это Arc; если браузер по умолчанию сменится, команда откажет до разблокировки, поскольку текущий системный помощник умеет завершать только Arc.

Telegram доступен один раз за календарный день по локальному времени Mac, по умолчанию на 15 минут. `telegram --set-minutes 10` сохраняет длительность следующих сессий; допустимо 1–90 минут. Изменение длительности не сбрасывает дневной лимит и не продлевает текущую сессию. Повторный запуск не создаёт второй таймер.

YouTube и Instagram не печатают обратный отсчёт и обычные сообщения о начале/окончании доступа. Telegram выводит одно короткое сообщение и сразу возвращает управление терминалу.

## Состояние и автоматическое закрытие

История, настройки и время последнего запуска хранятся в `~/.focus_open/state.json`. Запись атомарная с fsync. День резервируется до выдачи доступа, поэтому закрытие терминала между выдачей доступа и открытием браузера не позволяет получить вторую сессию. Повреждённый файл состояния вызывает отказ, а не обнуление лимитов.

Существующий root-помощник хранит срок текущего доступа в `/Library/PrivilegedHelperTools/focus-open/lease.json`. Служба `local.focus-open.timer` проверяет его каждые полсекунды. При истечении времени завершает Arc, возвращает записи hosts и сбрасывает DNS. Это прекращает действующие соединения, включая WebSocket. При перезапуске службы или загрузке Mac незавершённый доступ закрывается сразу. Полностью выключенный или спящий Mac выполнит восстановление после запуска/пробуждения.

Cookies, localStorage и профили браузера не удаляются; вход в Telegram сохраняется средствами браузера. Содержимое, которое браузер уже закешировал для офлайн-просмотра, не стирается.

## Домены Telegram

В отдельном блоке hosts перечислены 21 домен, каждый для IPv4 и IPv6:

- `web.telegram.org`;
- `pluto`, `venus`, `aurora`, `vesta`, `flora` под `web.telegram.org`, также варианты `-1`;
- `kws1`–`kws5` под `web.telegram.org`, также варианты `-1`.

`/a/` и `/k/` используют тот же основной домен. Список основан на [документации транспортов Telegram](https://core.telegram.org/mtproto/transports) и [конфигурации Telegram Web K](https://github.com/morethanwords/tweb/blob/master/src/lib/mtproto/dcConfigurator.ts).

`telegram.org`, `127.0.0.1:8787`, SSH-туннель Mention Inbox, notifier, Aeza и Telegram session не изменяются. Другие блоки hosts сохраняются.

## Установка обновления

Установщик предназначен для Mac с уже существующими блоками YouTube/Instagram. Он создаёт резервные копии клиента и hosts, добавляет Telegram и проверяет sudoers перед заменой клиента.

```sh
sudo /usr/bin/python3 -I install.py
```

После установки открой новое окно Terminal: alias `telegram` добавлен в `.zshrc`. Постоянное разрешение sudo ограничено пятью точными командами помощника: `check`, `restore`, `lease youtube`, `lease instagram`, `lease telegram`. Произвольные команды, аргументы и запуск daemon не разрешаются без пароля. Код помощника принадлежит root; пользователь не может его заменить.

## Проверки

```sh
/usr/bin/python3 -B -m unittest test_focus_open test_safety test_limits
```

Тесты используют временные hosts/state и подменяют системные действия. Они проверяют повторные ссылки, 15-минутный срок, календарный день, активную сессию, сохранение настройки, отказ при повреждённом состоянии, восстановление после рестарта и независимость таймера от ввода в терминале. Личные state/config/lease и отчёты проверок исключены из Git.
