# Focus Blocker

Локальный блокировщик YouTube, Instagram, X, Telegram Web и VK Видео для macOS. Доступ контролируют защищённая системная служба, блоки `FOCUS_BLOCK` в `/etc/hosts` и наблюдение за адресами вкладок. Расширение браузера не требуется.

## Доступ

Каждый временный сервис можно открыть один раз за календарный день по Москве. Дневные лимиты независимы; новый день начинается в 00:00 `Europe/Moscow`.

| Сервис | Время | Команда |
| --- | --- | --- |
| Instagram | 2 минуты, главная страница без ввода ссылки | `instagram` |
| X / Twitter | 2 минуты, главная страница | `x` |
| Telegram Web | 7 минут | `telegram` |
| Обычный YouTube | Одно выбранное видео | `youtube` |
| Учебные видео из белого списка | Постоянно, без таймера | Прямая ссылка или `youtube --course …` |
| VK Видео | Постоянно заблокирован | — |

`youtube` запрашивает ссылку без меню выбора курса. Для обычного видео разрешён только его ID: переход на другой ролик закрывает доступ. Разные формы одной ссылки считаются одним видео. Дополнительно действует максимум два открытия обычного видео за сохранённую историю.

Длительность обычного видео определяется через уже установленный `yt-dlp`: длительность плюс две минуты запаса, максимум шесть часов. Получение метаданных ограничено 12 секундами; если оно не удалось, сессия длится 12 минут. Этот запрос не создаёт отдельного общего доступа к YouTube.

Одновременно действует одна временная сессия. Если выполнить `instagram`, пока идёт таймер YouTube, терминал предложит завершить YouTube и открыть Instagram. Ответ `да` закрывает прежний доступ и запускает окно Instagram; любой другой ответ оставляет прежнюю сессию. Это работает для всех временных сервисов. Если выбранный сервис уже использован сегодня, прежняя сессия сохраняется.

`focus-open stop` досрочно завершает текущую временную сессию. Для конкретного сервиса доступны `youtube --stop`, `instagram --stop`, `x --stop` и `telegram --stop`. Остановка не возвращает дневное открытие и не сбрасывает счётчик видео. Учебный белый список остаётся доступен.

## Учебный белый список

В `youtube-policy.json` включены:

- «Глубинное обучение 1 2023/2024»: `youtube --course dl`;
- «Ввведение в глубинное обучение. Семинары»: `youtube --course dl-seminars`;
- весь канал «Мопторий ФКН»: `youtube --course seminars`.

Белый список не расходует дневное открытие YouTube и не занимает временную сессию. Можно смотреть несколько лекций подряд, возвращаться к ним после истечения обычного доступа и одновременно пользоваться разрешённым окном другого сервиса. Ссылки для возвращения печатаются в терминале. `youtube --courses` показывает доступные учебные материалы.

Плейлисты с `auto_refresh: true` обновляются по публичным данным YouTube примерно раз в минуту. Для канала используется автоматически созданный YouTube плейлист всех загрузок: `UU` и часть ID канала после `UC`. Проверяется владелец плейлиста. Новые опубликованные видео канала добавляются независимо от ручных учебных плейлистов. Сбой сети сохраняет последний проверенный список и не останавливает таймеры.

Один параметр `list` или `channel_id` в адресе не разрешает чужой ролик: ID видео должен присутствовать в защищённом списке. Разрешённые страницы канала доступны для выбора видео. Shorts разрешены только для проверенных видео разрешённого канала; общая лента, поиск YouTube и посторонние каналы не открываются без отдельного разрешения на конкретное видео.

Видеопредпросмотр Google блокируется отдельно, в том числе ссылки с `fpstate=ive` и `vld`. Для разрешённых лекций используйте прямые ссылки YouTube.

## Установка и обновление

Нужны macOS, системный `/usr/bin/python3` версии 3.9 или новее и `python3` в пользовательском PATH. Зависимости Python не устанавливаются. `yt-dlp` нужен только для автоматического определения длительности обычного видео.

```sh
sudo /usr/bin/python3 -I install.py
```

Установщик копирует помощник и все три модуля, сохраняет защищённый белый список, создаёт все блоки hosts и запускает `local.focus-open.timer`. Команды устанавливаются в `~/.local/bin`, путь добавляется в `.zshrc`. Откройте новое окно терминала. Если macOS запросит разрешение Automation для браузера, подтвердите системный диалог.

Повторная установка сохраняет существующие защищённые счётчики, историю и актуальный кэш плейлистов. Старые установки без защищённых счётчиков получают их из сохранённой истории. Повреждённые данные вызывают отказ. Активную временную сессию установщик не прерывает: обновление нужно повторить после её окончания. Резервная копия создаётся в `/Library/PrivilegedHelperTools/focus-open/backups/`; при ошибке замены файлов восстанавливается предыдущая установка.

Прочие строки hosts сохраняются. VK Видео блокируется на `vkvideo.ru`, его служебных поддоменах и `video.vk.com`; обычный `vk.com` не блокируется целиком. Telegram API и отдельные приложения уведомлений не входят в веб-лимит Telegram.

## Как работает служба

Код помощника, политика и счётчики принадлежат root. Пользовательский `~/.focus_open/state.json` хранит историю для отображения; его редактирование не сбрасывает защищённый дневной лимит. Разрешение sudo ограничено одиннадцатью точными командами помощника. Запуск произвольного кода или `daemon` через это разрешение недоступен.

Служба проверяет временные сессии каждые полсекунды. Для сроков используются время UTC и общий для процессов `CLOCK_MONOTONIC`. Завершение команды, закрытие терминала и изменение пользовательского состояния не продлевают доступ. При перезапуске службы незавершённая временная сессия отзывается, а постоянный учебный список сохраняется.

Наблюдатель поддерживает Arc, Chrome, Chrome Canary, Edge, Brave, Dia и Safari. Запрещённые вкладки закрываются по идентификатору; остальные вкладки сохраняются. Ошибки наблюдения учитываются отдельно для каждого браузера. Если закрытие нельзя подтвердить, служба блокирует YouTube и при необходимости останавливает затронутый браузер. Ошибка чужого браузера не должна обнулять действующий срок Telegram или Instagram. Проверка запущенной службы использует состояние launchd, поэтому занятой наблюдателем блокировочный файл не считается поломкой таймера.

Система проверяет адреса вкладок и известные домены. Она не фильтрует каждый сторонний iframe или произвольный сетевой клиент. Браузеры, которые наблюдатель не поддерживает, вызывают отказ в доступе к YouTube. Администратор macOS может изменить или отключить службу.

## Проверки

```sh
/usr/bin/python3 -B -m unittest discover -p 'test_*.py'
```

Тесты используют временные файлы и подменяют системные действия. Проверяются дневные лимиты по Москве, сохранение счётчиков, отдельный доступ к видео, постоянные плейлисты и каналы, добавление будущих загрузок, поддельные параметры адресов, Google-предпросмотр, сбои браузеров, гонки вкладок, восстановление блокировок и общий источник времени между процессами. Личная история, локальные конфигурации, активные сессии, журналы и резервные копии в Git не сохраняются.
