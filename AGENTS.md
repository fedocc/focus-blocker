# Работа с проектом

Для установки новой учебной системы на Mac следуй START_HERE.md и CODEX_SETUP.md.
Пользовательские аккаунты и адрес Слова выбирает получатель. Не копируй исходные
preferences.json, collection.anki2, study.json, базы, .env или user_files в Git.
Не запускай 80-минутный защищённый блок для проверки интерфейса или установки.
Не архивируй существующие карточки автоматически.

Обычные проверки кода: `python3 -B -m unittest discover -p 'test_*.py'`.
Проверка чистой сборки: `python3 doctor.py --source-only`.
Привилегированный установщик запускается владельцем Mac в соответствии
с разрешениями среды; диагностические тесты используют подмены системных действий.
