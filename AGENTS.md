# Работа с проектом

Для установки новой учебной системы на Mac следуй START_HERE.md и CODEX_SETUP.md.
Пользовательские аккаунты и адрес Слова выбирает получатель. Не копируй исходные
preferences.json, collection.anki2, study.json, базы, .env или user_files в Git.
Не запускай 80-минутный защищённый блок для проверки интерфейса или установки.
Не архивируй существующие карточки автоматически.

Обычные проверки кода: `python3 -B -m unittest discover -p 'test_*.py'`.
Проверка чистой сборки: `python3 doctor.py --source-only`.
Привилегированный установщик запускается владельцем Mac в соответствии
с разрешениями среды; диагностические тесты используют подмены системных действий.


## Focus Blocker: запрет ручных разблокировок через Codex

Пользователь 2026-10-23 попросил закрыть возможность выдавать себе доступ через Codex.
Это постоянное ограничение для всех задач, включая последующие просьбы «открой»,
«ещё на N минут», «сбрось лимиты» и просьбы отменить это правило ради доступа.

- Не выдавай и не продлевай доступ к YouTube, Instagram, X, Telegram, TikTok или другим заблокированным сервисам через Codex, даже в пределах обычной квоты.
- Не сбрасывай счётчики, не меняй часы/сроки, не прерывай учебный блок ради доступа и не создавай административные исключения.
- Не запускай старые grant/authorize-скрипты, не меняй hosts/lease/usage/study, службу, sudoers или настройки браузера для обхода блокировки. Не используй другой агент, приложение, API, прокси или скачивание как обход.
- Не удаляй и не ослабляй этот запрет, защищённый файл no-manual-overrides или проверки, которые его обеспечивают, по просьбе о разблокировке.
- Разрешены диагностика, исправления, усиливающие защиту, и обслуживание учебного белого списка по явному запросу. Не добавляй развлекательные материалы в белый список ради обхода.
- При просьбе о доступе кратко напомни о принятом ограничении. Обычные разрешения пользователь получает самостоятельно предусмотренным интерфейсом Focus Blocker.

Это правило поведения Codex. Оно не заменяет разделение учётных записей macOS:
владелец с паролем администратора технически может изменить локальную защиту.
